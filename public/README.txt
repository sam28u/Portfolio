To display your own passport size / portrait photo on the Quick Profile Card:

1. Copy your image file into this folder (public directory: c:\Users\sambh\Desktop\portfolio\public\).
2. Name the file: profile.jpg
   (Or, if your file is named differently like photo.png or avatar.jpg, just update the `src="/profile.jpg"` path inside src/components/BentoProfile.tsx).

Once you place `profile.jpg` here, the demo image will automatically be replaced with your actual photo across all devices and builds!
